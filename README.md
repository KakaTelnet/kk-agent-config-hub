# AGENTS.md Hub

用于收集值得参考的 AGENTS.md，并按类型和版本整理规则。

## 目录

- `collection/`：收集到的外部 AGENTS.md 原文及来源记录，按来源归档。
- `kaka/`：整理后的 AGENTS.md，按类型分类、按版本保存。

## 个人规则约定

每个类型使用独立目录，版本目录中保存该版本的 `AGENTS.md`：

```text
kaka/
  <类型>/
    v1/
      AGENTS.md
```

新版本通过新增版本目录保存；不要覆盖旧版本。类型目录中的 `README.md` 可记录当前使用版本及版本变更摘要。

## 收集外部规则

每个来源单独建目录，保存原始 `AGENTS.md`，并在同目录的 `README.md` 记录来源链接、获取日期和必要的上下文。保留原文，整理后的内容放在 `kaka/`。
